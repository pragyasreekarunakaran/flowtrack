# FlowTrack 🚀

FlowTrack is a Developer Productivity Analytics MVP that helps teams understand engineering performance using key metrics.

## 🔍 Features
- Lead Time tracking
- Cycle Time analysis
- Deployment Frequency
- Bug Rate insights
- Actionable recommendations

## 🧠 Goal
To convert raw engineering data (PRs, Jira, CI/CD) into meaningful insights for developers and managers.

## 🛠 Tech Stack
- React + Vite
- JavaScript
- Mock Data (JSON)

## ▶️ How to Run
1. npm install
2. npm run dev
